# AI VinUni Prep Studio

Web tĩnh để ôn bài kiểm tra đầu vào khóa 3 chương trình AI thực chiến: lý thuyết ML/DL, toán định lượng, Python/pandas/NumPy, trắc nghiệm, code lab, đề mô phỏng 90 phút, tài nguyên video/tài liệu ngay trong từng bài và câu tự luận tình huống.

## Cách mở

Mở trực tiếp `index.html` trong trình duyệt.

## Nội dung chính

- Module A: xác suất, Bayes, thống kê, confusion matrix, ma trận, gradient.
- Module B: Python core, NumPy, pandas, data cleaning, feature engineering.
- Module C: ML/DL, pipeline, overfitting, metrics, CNN/RNN/Transformer, AI product.
- Module D: logic, đạo đức AI, fairness, privacy, short-answer scenarios.
- Bộ đề full: 8 đề luyện tập tự tạo và 3 đề `AI-TEST gốc gom trùng` được trích từ bundle AI-TEST của bạn, mỗi đề 60 câu/90 phút với module A/B/C/D, code tay và tự luận tự chấm trong workspace riêng.

Tiến độ học, code lab và nháp tự luận được lưu bằng `localStorage` của trình duyệt.

## Lưu ý

Không có nguồn chính thức công bố đề chi tiết từng câu, nên web này không cam kết đậu 100%. Nội dung được xây để che phủ kiến thức nền và dạng tư duy thường được nhắc trong thông tin tuyển sinh/review công khai.

Hai trang AI-TEST cộng đồng được dùng để tham khảo cấu trúc. File `ai-test-curated.js` được sinh từ bundle AI-TEST của bạn, đã dedupe 600 câu gốc còn 162 câu unique và gom thành 3 đề:
